# 1.4.1 — Bayi kullanıcı oluşturma geri bildirimi

Mevcut ERP/platform hesabında kayıtlı e-postayla bayi kullanıcısı oluşturma isteği benzersiz e-posta kuralına takılıyordu. Genel 409 mesajı formun dışında kalıyordu.

- Oluşturmadan önce e-posta çakışması kontrol edilir; yarış durumundaki unique-index hatası da aynı anlaşılır `B2B_EMAIL_IN_USE` yanıtını verir. Mevcut kullanıcı/rol/tenant bağlantısı değiştirilmez.
- Hata formun içinde görünür. Başarılı kayıtta bayi kullanıcı listesi açılır, oluşturulan kullanıcı ve başarı mesajı gösterilir; parola alanı temizlenir.
- Kapalı bayi için oluşturma formu yerine aktivasyon yönlendirmesi gösterilir. Backend ayrıca müşteri aktifliğini doğrular.
- Kullanıcı limiti ve kapalı müşteri ayrı hata kodlarıyla açıklanır. Paket limitleri kaldırılmaz.
- Girilen parolanın başındaki/sonundaki boşluklar sessizce değiştirilmez; parola aynen hashlenir.

Değişen dosyalar: `public/b2b/admin.js`, `src/modules/b2b/routes.js`, `tests/b2b.test.js`, `package.json`, `package-lock.json`, bu sürüm raporu.

Doğrulama: B2B API testleri çakışan e-posta, yeni hesap, unique-index yarışı ve parola doğruluğunu kapsar. Yerel Chrome testi form içi hatayı, başarı sonrası kullanıcı listesini ve temiz parola alanını doğrular (390 px, yatay taşma yok). Test hesapları canlı veritabanında oluşturulmaz.
